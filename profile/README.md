<h3 align="center">Sign your videos. Make them verifiable.</h3>

Tectra provides video authentication for camera companies, AI video platforms and creators.

- **Sign:** watermark an export and register its delivered file with a source declaration.
- **Share:** keep the registered original and distribute the video.
- **Verify:** authenticate an exact original against its signed record, or identify a shared copy’s registered source.

Exact-file verification requires a content-bound record. Editing, re-encoding or metadata changes may break that match. A detected watermark can survive edits; it does not establish that a shared copy is unedited. No mark found does not mean human-made.

The archived `sdk-ts` and `tectra-verify` repositories and the `tectravision-sdk` Python package describe legacy integrations. Use the current hosted API for new video integrations. Customer-hosted marking is a separate, restricted deployment arrangement.

Camera capture signing requires a device/recorder integration. Creators can link a registered video record to an edition or NFT; minting and ownership transfers belong to the integrating platform.
